# Bird | From Site to Service

Interactive mission-critical campus journey, grounded in public Bird sources. Static HTML, CSS and JavaScript; no backend, no telemetry.

Live site: https://condigitalexpert.github.io/bird-self-perform-journey/

The page opens in story mode: a predetermined walk from the energy source to the white space. Right, Down, Page Down and Space go to the next step; Left, Up and Page Up go back; scroll or swipe scrubs. Press H for the shortcut list, E to edit the text, photos and client logo (saved in your browser; Export JSON and Import JSON move the edits between machines), X for the explorer view, P and G to save a PNG or a GLB of the model. Add `?review` to the address to see where the crew photos go.

Illustrative campus. Not a project design, estimate, programme or scope commitment. Published 7 October 2026.
